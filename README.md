# Proyecto-Refugio
Proyecto Refugio de animales
Programacion orientada a objetos
Integrantes: Vicente Galetto - Manuel Norona

El problema se adapta al paradigma de Programacion a objetos ya que para la resulucion del mismo va a ser necesario
implementar metodos capaces de crear o modificar distintos objetos, con caracteristicas distintas, capaces de interactuar unos con
otros, abstraer los datos innecesarios, o modificar el comportamiento de cada uno segun sea necesario
